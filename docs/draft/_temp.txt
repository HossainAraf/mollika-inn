13. One more architectural point: price update should also refresh rooms

Your current design should behave like this:

Initial page
Room type:       Select room type
Check-in:        Today
Check-out:       Tomorrow
Room number:     No available rooms
Price:           0
Admin selects
Room type: Deluxe
Check-in: 15 Sep
Check-out: 18 Sep

and clicks:

[ Update ]

Rails performs GET /admin/bookings/new.

Then:

@room_type
@check_in
@check_out
@available_rooms
@price
@nights
@total

are calculated.

The page comes back with:

Room type:       Deluxe
Room number:     [D-101 ▼]
                 [D-102]
                 [D-103]

Rate per night:  ৳3000
Nights:          3
Total:           ৳9000

That's the clean behavior you want.
